## 明确边界

- 没有使用 WebView 包装仪表盘、博客或工具。Turnstile 是唯一必要的网页验证流程。
- 不是 kudo 全应用的逐像素复刻；复用其玻璃渲染技术，CF 仪表盘保持原有终端结构。尚未通过截图对照验收。
- 管理排序使用原生上移/下移按钮；未复刻网页拖拽手势。设置为完整、类型保留的原生字段编辑器，未逐个复刻原后台的所有专用表单。
- 第三方网站主题只能管理配置，不能直接作为原生 Compose 主题执行。
- 博客域名/发布问题未进行线上修改；ZIP 离线阅读功能保留内容加密。
- 66 的另一套健康检测服务未并入 CF 模块；不能把不同系统的 API 当成同一个探针。
- 未做 Android 编译和真机验证；交付不得标为「完整功能已真机验收」。

核心验证：`tools/test-core.ps1` 已通过 28 项；`tools/check-syntax.ps1` 使用 Kotlin PSI 解析 23 个应用源文件，0 个语法错误。Gradle Wrapper 通过独立的无 Android 空工程生成；该步骤成功不代表 Android App 构建成功。
